🚀 Guia de Deploy e Integração
1
Publicar na Vercel — 2 minutos, grátis
1. Renomeie o arquivo para index.html
2. Acesse vercel.com → "Add New" → "Project" → arraste o arquivo
3. Clique "Deploy" → URL pública em ~30 segundos (ex: doramaverse.vercel.app)
4. Compartilhe a URL — funciona em celular e desktop sem instalar nada
2
Chat em Tempo Real — Firebase (grátis até 100 conexões)
1. console.firebase.google.com → "Criar projeto" → nome: doramaverse
2. Realtime Database → "Criar banco" → Modo de teste
3. ⚙️ Configurações → "Seus apps" → "Web" → copie o objeto firebaseConfig
4. No HTML, substitua o objeto FB_CONFIG pelos seus valores e faça novo deploy
✅ Com Firebase configurado, o chat funciona entre todos os usuários em tempo real. O chat local (fallback) já funciona para testes na mesma aba.
3
Video Rooms reais — Daily.co (grátis 200 min/mês, sem backend)
Por que não Twilio? Twilio Video cobra ~$0,004/min/participante + exige servidor Node.js. Daily.co é iframe puro, muito mais simples e barato.
1. Crie conta em daily.co → Dashboard → API Keys → copie sua key
2. Substitua a constante DAILY_DOMAIN pelo seu domínio no HTML
3. Na função openRoomById(): descomente o bloco do iframe e remova a simulação de câmeras
💡 Alternativa mais simples: Whereby Embedded — crie sala permanente no dashboard, embed como iframe. Zero API, zero backend.
4
Validação real de Pix — Mercado Pago Webhook
Sem isso, qualquer usuário clica "Já paguei" e ganha Premium de graça. O webhook elimina esse risco.
1. mercadopago.com.br/developers → Credenciais → copie access_token
2. Gere cobrança Pix via API: POST https://api.mercadopago.com/v1/payments com payment_method_id: "pix" → recebe QR code real
3. Configure Webhook no painel MP → URL do seu backend → evento payment
4. Backend verifica status === "approved" → atualiza /users/{uid}/plan no Firebase → usuário vê Premium automaticamente
⚠️ O botão "Já Paguei" atual é apenas para testes do MVP. Remova-o antes do lançamento público e ative o plano somente via webhook confirmado.
5
Gerenciamento de Acesso
Firebase Authentication: gerencia login/cadastro — email+senha, Google, etc. UIDs únicos por usuário.
Firebase Realtime Database Rules: chat só para plan === "premium", DMs só entre usuários com match mútuo registrado.
Painel Admin (já implementado): admin@doramaverse.com / admin123 — ver usuários, promover/rebaixar planos, monitorar receita.
Firebase Console: console.firebase.google.com → Database → visualize e edite dados em tempo real.
